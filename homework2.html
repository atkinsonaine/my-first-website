My First Styled Page

A simple example of how HTML and a separate CSS file work together.

What I’m learning

HTML gives a page its structure, while CSS controls its appearance. Keeping the styles in a separate file makes the page easier to update.

CSS building blocks

  • Selectors choose which HTML elements to style.
  • The box model uses margin, padding, and borders.
  • Color helps create a consistent visual theme.

A quick tip

Save both files, then refresh this page in your browser to see CSS changes.
