Learning CSS Styling

CSS is the language that styles a webpage. It controls how HTML content looks, from its colors and fonts to the space around each element.

How CSS works

A CSS rule has a selector, which chooses the HTML elements to style, and declarations that set their appearance. Each declaration has a property and a value.

p {
    color: #54285f;
    font-size: 18px;
}

In this example, p selects paragraphs, and the declarations change their text color and size.

Three useful selector types

Type selector

Selects every element with a given HTML tag.

h2 { color: purple; }

Class selector

Selects elements that share a class. In CSS, a class starts with a dot.

.highlight { background: pink; }

ID selector

Selects the element with a matching ID. In CSS, an ID starts with a hash.

#page-title { color: purple; }

The box model

Each HTML element can be thought of as a box. The content sits inside the padding, then the border, with margin outside the border to create space between elements.

Content inside the box

What I learned: CSS rules can make a page easier to read and give it a consistent look. Using selectors and the box model helps style different parts of a page in an organized way.
