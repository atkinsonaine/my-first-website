Example: This Current Page will Not Fit on a Phone

In this example, the layout I created I intentionally fixed the box at 1500 pixels wide and added no CSS @media query. With phone screens being much narrower, this current layout will not fit properly, so part of the example goes off-screen and requires sideways scrolling. This demonstrates how your website may look less polished, less user-friendly, and less accessible when using responsive design techniques.People may have harder time accessing the content on a smaller screen but this can be easily fixed.

With that being said we can use CSS @media queries to make our layout responsive cleaner and Ultimaly user friendly for all devices.
